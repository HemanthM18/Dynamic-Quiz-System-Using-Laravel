# Dynamic Quiz System (Laravel)

## Features
- Create quizzes
- Multiple question types (binary, single, multiple, number, text)
- Image + video support
- Option images supported
- Quiz attempt + auto scoring

## Setup
1. git clone ...
2. composer install
3. cp .env.example .env
4. Configure DB
5. php artisan migrate
6. php artisan storage:link
7. php artisan serve

## Tech Stack
- Laravel
- MySQL
- Blade + Bootstrap

## Notes
- Supports extensible question types
